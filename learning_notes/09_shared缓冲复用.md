# 第 9 节：shared memory 的边界处理与缓冲复用

## 目标与输入

让一个 block 用同一块 shared memory 连续处理两批数据，练习合作加载、补零、跨 warp 读取和两次同步。输入 `A` 长度 96，输出 `B` 长度也为 96，均为 `float`。启动 1 个 block、64 个线程，执行两轮：每轮处理 64 个元素，第二轮只有前 32 个有效。

每轮输出规则：线程 `t` 读取本轮中另一个 warp 的相同 lane 所装入的值，即 shared 元素 `(t + 32) % 64`；输入越界时该位置填 `0`，输出越界则不写。

## 线程和内存

```text
block 0：64 线程，warp 0 = thread 0～31，warp 1 = thread 32～63
                每个 warp 的 lane 编号为 0～31

第 0 轮（base = 0）
global A[0～63] ──线程合作加载──→ shared tile[0～63]
                                  │ 同步 ①：所有写入完成
global B[0～63] ←──跨 warp 读取── tile[0～63]
                                  │ 同步 ②：所有读取完成，才可覆盖 tile
第 1 轮（base = 64）
global A[64～95] ──warp 0──→ tile[0～31]
输入越界          ──warp 1──→ tile[32～63] 填 0
                                  │ 同步 ①
global B[64～95] ←─warp 0 读取── tile[32～63]
warp 1 输出越界，不写 B           │ 同步 ②
```

这些数字都是元素索引。`tile` 是 block 私有的 shared 数组；同一轮中各线程写不同的 `tile[t]`。输入越界的线程也必须写零并参加同步，不能提前 `return`。

## 手算和同步依赖

假设 `A[i] = i + 1`：

- 第 0 轮，thread 0 从 `tile[32]` 读到 33，写 `B[0] = 33`；thread 32 从 `tile[0]` 读到 1，写 `B[32] = 1`。
- 第 1 轮，thread 0 读取无效输入位置所对应的 `tile[32]`，该位置被填 0，所以 `B[64] = 0`。

同步 ① 防止某个 warp 在另一个 warp 写入前读取。同步 ② 防止一个 warp 开始下一轮、覆盖 shared 数据，而另一个 warp 还在读上一轮。最后一轮之后没有后续复用，但为了让循环结构统一，本练习每轮都保留同步 ②。两处同步都由整个 block 无条件执行。
